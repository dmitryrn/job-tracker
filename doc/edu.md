# Master's Degree Coursework

## Master's Final Project: Startup Product Development

Developing a startup product as the master's final project. To support the product's user-facing goals, the planned system will use prompt-driven, agentic AI pipelines and an evaluation framework for comparing model outputs across controlled variables, such as model choice, prompt configuration, and input code. The framework will assess output quality and effectiveness rather than relying only on raw model responses.

Acting as the software architect and primary developer. The planned system includes microservices, APIs, a frontend, multiple database technologies, centralized logging, observability, metrics, testing, and evaluation between pipeline stages.

## Separate Machine Learning Course: Two Semesters

### Semester 1: Python and Data Analysis

Python programming foundations, including collections, functions, file handling, object-oriented programming, error handling, special class methods, and external libraries. Applied Python data analysis covered linear algebra with NumPy, descriptive statistics and data analysis with pandas, visualization with Matplotlib and seaborn, regression analysis, and Git.

### Semester 2: Machine Learning and Deep Learning

Mathematical foundations and classical machine learning: k-nearest neighbors, probability and Naive Bayes classification, optimization, logistic regression, support vector machines, decision trees, random forests, classification-quality and feature-importance evaluation, gradient boosting, and unsupervised learning and clustering.

Deep-learning topics included stochastic-gradient-descent improvements, word embeddings, recurrent neural networks and vanishing gradients, and convolutional neural networks for image processing.
